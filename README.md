### Sales Insights Data Analysis using Power BI



##### Project Overview



The project analyzes the sales performance of Atliq Hardware, a computer hardware company, utilizing Power BI. The dashboards help uncover trends, identify high-value customers, and evaluate market performance for better decision-making.



##### Objectives



* Track sales revenue and profit trends.



* Identify key customers and their revenue contribution.



* Compare market performance across regions.



* Support business strategy with data-driven insights.

##### Tools \& Technologies



* MySQL – data storage and SQL queries.



* Power BI – dashboard building and reporting.



* DAX – for custom measures.



* Dataset – Atliq Hardware (from Codebasics case study).
